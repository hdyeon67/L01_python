# 고급 데이터 분석 챌린지 가이드

본 디렉토리(`hard`)의 문제들은 순수 파이썬(Vanilla Python)만을 사용하여 데이터 분석 라이브러리(Pandas 등)의 핵심 동작 원리를 직접 구현해보는 것을 목표로 합니다.

## 문제 구성 및 제안 배경

| 문제 | 제목 | 실무 연계성 | 주요 역량 |
| :--- | :--- | :--- | :--- |
| **C1** | 데이터 결합 (JOIN) | SQL Join, ID 기반 데이터 맵핑 | 다중 딕셔너리 핸들링, 키 매칭 로직 |
| **C2** | 이상치 탐지 | 데이터 정제(Cleaning), 통계 기초 적용 | 수식 구현, 조건부 필터링 |
| **C3** | 다중 그룹 집계 | Pivot Table, Group By 동작 원리 이해 | 중첩 딕셔너리 구조 설계, 데이터 요약 |

## 제안 사항의 차별점

1.  **현업 지향적**: 단순 알고리즘 문제보다 실제 데이터 분석 현업에서 발생하는 "두 데이터를 합쳐라", "이상한 데이터를 빼라", "지역별로 요약해라"와 같은 요청을 파이썬 로직으로 치환했습니다.
2.  **구조적 사고**: 중첩 딕셔너리와 리스트를 자유자재로 다루는 연습을 통해 복잡한 JSON 데이터를 다루는 데 필요한 근육을 길러줍니다.
3.  **라이브러리 이해도**: 나중에 Pandas를 배우더라도 `.merge()`, `.groupby()`가 내부적으로 어떤 식의 반복과 조건 판단을 거치는지 이해하게 되어 활용도가 높아집니다.
